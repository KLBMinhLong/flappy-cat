# 🐱 Flappy Cat — Mobile Build Guide

## 📋 Prerequisites

1. **Android Studio** — Download: https://developer.android.com/studio
2. **JDK 17+** — Already installed
3. **Node.js** — Already installed
4. **Google AdMob account** — https://apps.admob.com
5. **Google Play Console** — https://play.google.com/console ($25 one-time)

## 🔧 Build Steps

### 1. Install Android Studio
- Download and install Android Studio
- During setup, install Android SDK 34+
- Set `ANDROID_HOME` environment variable

### 2. Build the APK
```bash
# Install dependencies
npm install

# Copy web assets & sync to Android
npm run cap:build

# Open in Android Studio
npm run cap:open
```

### 3. In Android Studio
- Wait for Gradle sync to finish
- Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**
- APK will be in `android/app/build/outputs/apk/debug/app-debug.apk`

### 4. Generate Signed APK (for Play Store)
- In Android Studio: **Build > Generate Signed Bundle / APK**
- Choose **Android App Bundle** (recommended for Play Store)
- Create a new keystore (save it somewhere safe!)
- Build release AAB

## 💰 AdMob Setup

### 1. Create AdMob Account
- Go to https://apps.admob.com
- Create an app: "Flappy Cat" (Android)
- Create 3 ad units:
  - **Banner** — for bottom of screen
  - **Interstitial** — shown after game over
  - **Rewarded** — "watch ad to continue"

### 2. Update Ad IDs
Replace test IDs in these files:
- `index.html` → search for `ca-app-pub-3940256099942544` (test IDs)
- `android/app/src/main/AndroidManifest.xml` → AdMob App ID

### 3. AdMob Policies
- ✅ Don't show interstitial on app launch
- ✅ Don't show interstitial on every game over (every 3-5 games)
- ✅ Rewarded ads are optional (user chooses to watch)
- ✅ Don't click your own ads

## 📱 Google Play Upload

### 1. Create Play Console Account
- Go to https://play.google.com/console
- Pay $25 one-time registration fee
- Complete identity verification

### 2. Create App Listing
- App name: "Flappy Cat"
- Short description: "🐱 Mèo mướp bay qua ống nước! Flappy Bird với 12 skins, power-ups, và nhiều chế độ chơi!"
- Full description: (see itch.io description)
- Screenshots: Take from Android Studio emulator
- Feature graphic: 1024x500 banner image
- Category: Games > Arcade

### 3. Upload AAB
- Go to **Release > Production**
- Create new release
- Upload the signed AAB file
- Set target audience: Everyone
- Fill out content rating questionnaire
- Submit for review
